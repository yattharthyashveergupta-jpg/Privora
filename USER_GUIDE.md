## 1. Core Principles & Privacy Guarantees

Privora is built on four immutable enterprise guarantees:
1. **Zero External Data Exfiltration**: Document text, extracted chunks, tabular numbers, and user queries never leave your local machine or corporate intranet.
2. **Deterministic Evidence Citations**: Every claim generated by the assistant is grounded in specific, clickable document excerpts with exact page numbers, section headings, or spreadsheet cell ranges.
3. **No LLM Math Hallucinations**: Tabular numbers, column sums, averages, and coordinate counts are computed directly by a Python deterministic arithmetic engine rather than by an LLM guessing.
4. **Resilient Local Storage**: Metadata, passage vectors, and audit trails are persisted in SQLite 3 with Write-Ahead Logging (WAL) for instant crash recovery.

## 2. Getting Started on Windows Desktop

### Installation & Launch
1. Run the installer: `Privora-Setup-1.1.0.exe`.
2. Follow the setup wizard to install Privora (installs to `%LOCALAPPDATA%\Programs\Privora` without requiring admin rights).
3. Check the box to create a Desktop shortcut.
4. Launch **Privora** from your Start Menu or Desktop.
5. Privora automatically boots the internal Python backend engine and launches directly into a sleek **Microsoft Edge App Mode** workstation window.

## 3. The First-Run Onboarding Wizard

On initial launch, Privora automatically opens an interactive onboarding modal:
1. **Ollama Connectivity Probe**: Privora automatically checks `http://127.0.0.1:11434` for a local Ollama instance.
2. **Model Selection & Recommendations**:
   - **Qwen 2.5 (7B)** *(Recommended)*: Exceptional reasoning, structured extraction, and compliance analysis.
   - **Llama 3.1 (8B)**: Conversational fluency and long-context synthesis.
   - **Qwen 2.5 (3B)**: Lightweight alternative for machines with 8 GB RAM.
3. **Download Helper**: If the recommended model is not yet pulled, Privora displays the exact command to run:
   ```powershell
   ollama pull qwen2.5:7b
   ```
4. **Offline Evidence Mode Ready**: If Ollama is not installed or offline, you can immediately proceed in **Offline Evidence Mode** to search, extract, and inspect documents.

## 4. Document Intelligence & Ingestion

Privora supports 5 document formats with structured coordinate tracking:

| Format | Parsing Engine | Capabilities & Coordinate Granularity |
| :--- | :--- | :--- |
| **PDF (`.pdf`)** | PyMuPDF | Multi-page text extraction, per-page citations (`Page 3`). |
| **DOCX (`.docx`)** | `python-docx` | Hierarchy preservation (`Section: Payment Terms`), markdown tables (`\| Col 1 \| Col 2 \|`). |
| **XLSX (`.xlsx`)** | `openpyxl` | Multi-sheet parsing, header repetition, exact cell coordinate citations (`Sheet: Financials \| Cells: B2:D14`). |
| **CSV (`.csv`)** | Native Sniffer + Engine | Automated delimiter sniffing (`,`, `;`, `\t`, `\|`), encoding fallback (`utf-8-sig`, `latin-1`), row-coordinate chunking (`CSV: Rows 2-10`). |
| **TXT / MD** | Native UTF-8 engine | Multilingual character sets, Unicode normalization (NFC), control-character stripping. |

### Uploading Documents
- Drag and drop files directly onto the **Documents** workbench or click **Upload Document**.
- Filter documents by type pills: `ALL`, `PDF`, `DOCX`, `XLSX`, `CSV`, `TXT`.
- Click on any document in the table to open the **Enclave Document Detail Drawer**.

## 5. Deterministic Tabular Intelligence & Spreadsheet Analytics

When inspecting an Excel (`.xlsx`) or CSV (`.csv`) document, open the **Numerical Intelligence** tab in the document drawer:
- **Exact Arithmetic**: Computes exact totals (sums), arithmetic means (averages), min, max, and count.
- **Traceable Coordinates**: Every statistic displays the exact cell range (e.g., `B2:B25` or `Rows 2-25`) from which it was derived.
- **Deterministic Summary Passage**: A structured summary passage is automatically indexed into the retrieval database so that questions like *"What was our total Q1 spend?"* retrieve verified arithmetic instead of hallucinated math.

## 6. Interactive Grounded Chat & Traceable Citations

1. Navigate to the **Research** or **Chat** view.
2. Enter your question in natural language (e.g., *"What are our liability limits across all vendor agreements?"*).
3. The Okapi BM25 engine scans indexed passages and gathers the top matching evidence.
4. The local AI generates an answer with interactive bracketed citations (`[1]`, `[2]`).
5. **Clicking any citation pill**:
   - Opens the source document viewer.
   - Highlights the exact sentences or spreadsheet cells referenced in the answer.
6. **Unsupported Question Handling**: If the uploaded documents do not contain sufficient evidence to answer your query, Privora explicitly flags `insufficient_evidence: true` and informs you rather than making up facts.

## 7. Cross-Document Contradiction Auditing

Privora includes an automated contradiction analysis engine:
1. Navigate to **Analysis > Contradictions**.
2. Click **Run Contradiction Audit** to scan all documents in the active workspace.
3. The engine extracts comparative dimensions (e.g., *Payment Terms*, *Liability Caps*, *Effective Dates*, *Delivery Deadlines*) and surfaces conflicting claims.
4. Findings are categorized by severity:
   - **Critical / High**: Direct numerical or legal conflicts (e.g., *Contract A says Net 30, but Spreadsheet B says Net 60*).
   - **Medium / Low**: Terminology variations or timeline discrepancies.
5. **Pairwise Comparison**: Select any two documents to view side-by-side clause comparisons and pinpoint conflicts.

## 8. Offline Evidence Mode

When running without Ollama or when local LLM inference is disabled:
- Use **Evidence Search** to run lightning-fast lexical queries across your document archive.
- Inspect passages, view cell coordinates, and read full extractions.
- Privora remains 100% operational as a private document workbench even without an active neural model.

## 9. Multi-User Workspaces & Collaboration

In enterprise server deployments:
- **Workspaces** provide cryptographically isolated enclaves for departments (*Legal*, *Finance*, *Compliance*).
- **Granular RBAC Roles**:
  - `Owner`: Full organizational control, role reassignments, workspace deletion.
  - `Admin`: User invites, document uploads/deletions across the workspace.
  - `Member`: Document ingestion, search, chat, and analysis.
  - `Viewer`: Read-only access to documents, citations, and search results.

## 10. Transparent Privacy Diagnostics & Backups

### Real-Time Privacy Diagnostics
Navigate to **Settings > Privacy**:
- View the **Air-Gap Verification Status**: Loopback inference binding, active TCP socket count (0 WAN connections), and absence of cloud API keys.
- Real-time diagnostics clearly distinguish between **Hard Cryptographic Verifications** (local loopback socket checks) and **Informational Metrics** (database path, disk space).

### Disaster Recovery
- **Create Backup**: Generates an atomic, point-in-time `.zip` archive containing `workbench.sqlite3`, uploaded documents, and an SHA-256 `manifest.json`.
- **Restore Backup**: One-click restore with automated integrity checks and rollback on corruption.
